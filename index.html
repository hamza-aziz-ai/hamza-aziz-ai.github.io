Projects.

VoicePlug Inc.

DriveThru Voice Ordering Modernization

A real-time voice agent that takes DriveThru orders and files them into the POS, across multiple QSR brands. On FastAPI + Socket.IO, a speech layer streams the customer's words in, Gemini 2.5 Flash-Lite extracts menu items, an order agent replies from a cached menu-aware prompt, and a second model turns each spoken confirmation into Redis cart operations. The hard part is making a non-deterministic model safe to bill on: required-choice and per-item limit enforcement, a final cart check before submission, and staff handoff after repeated failures — deterministic code, validated against replays of real calls. MongoDB records, Jinja2 per-brand prompts, four POS integrations.

Personal Project

HalalLens — Halal Investment Research Copilot

A full-stack Shariah-compliance research platform for Indian equities. A FastAPI backend (34 REST endpoints) and a Next.js 14 + TypeScript front end sit over PostgreSQL, with an AAOIFI-style ratio engine deciding whether a stock screens clean. The piece worth building twice is the “Explain Why” narrator: it runs on deterministic rules by default, each verdict citing the filing date and the figures it was computed from, with an optional vLLM / OpenAI-compatible mode behind a config flag. Separate ingestion and evaluation containers crawl BSE announcements, pull financials out of PDF and XBRL filings, and refresh verdicts on a schedule.

Open Source

Codex–Claude Council — Two AIs, One Answer

An open-source plugin and MCP server that puts one question to both ChatGPT (via the Codex CLI) and Claude (via Claude Code). They answer independently, then reply to each other round after round until they agree — one model writes the final answer while the other checks it. Built on Node.js 20+ with zero runtime dependencies, speaking MCP over JSON-RPC/stdio, it runs locally on existing subscriptions with no API keys, across Claude Code, Codex, Claude Desktop and the ChatGPT app. On a 24-question benchmark of deliberately tricky programs, run from fresh sessions with no web search, it scored 24/24, matching the best single model while catching the other's one miss.

Global InfoVentures Pvt. Ltd.

Conversational AI for College ERP

A voice- and text-driven assistant that answers questions against live college ERP data across multiple client institutes. Audio is transcribed server-side through a FastAPI gateway, then a two-stage Rasa router picks the ERP module — asking a clarifying question and re-classifying when confidence is low, so an ambiguous query never reaches the LLM. Schema grounding is the hard part: each institute's hundreds of field mappings are embedded into Milvus and retrieved alongside similar few-shot examples, so Gemini 2.5 Flash emits constrained SQL fragments into a fixed payload contract instead of free-form SQL. The ERP executes it and a second model summarises the rows.

Global InfoVentures Pvt. Ltd.

PTZ Classroom Attendance — One Camera per Room

Classroom attendance from a single PTZ camera per room instead of a wall of fixed cameras. The system drives one ONVIF camera through a timed preset sweep — dedicated faculty captures at lecture start and end, then a 23-preset trace across the seats — with zoom and focus settling budgeted into every hop. Frames go to a TensorRT-backed InsightFace-REST service for detection and embedding, and identities come from a top-1 Milvus search over 512-d vectors. A separate YOLOv9 service counts heads independently; the two are reconciled per lecture and synced to the institute ERP. Four Dockerised services on a MIG-partitioned GPU, with PostgreSQL attendance logs.

Global InfoVentures Pvt. Ltd.

CCTV Face Recognition Attendance — Multi-Stream

The multi-stream sibling to the PTZ system. A producer process decodes 20+ live RTSP camera feeds — ROI crop and lighting check per frame — into a shared in-memory queue; a consumer batches 32 frames per request to InsightFace-REST, running as two TensorRT replicas on separate MIG slices behind nginx, where SCRFD (scrfd_10g_gnkps) detects and w600k_r50 embeds. Identities resolve by cosine search over a GPU-indexed Milvus collection. The gallery improves itself: high-confidence crops land in a staging collection that a nightly job folds into the index. Results persist to PostgreSQL, sync to the institute ERP, and stream back to on-site displays over Kafka.

Internship | Global InfoVentures Pvt. Ltd.

PPE Violation Detection

A browser-based PPE monitor: point it at an uploaded clip or a live camera URL and it streams the raw and annotated feeds back side by side over MJPEG. A custom-trained YOLOv7 model classifies every person in frame as compliant or violating at a 0.75 confidence gate, and a temporal rule waits for a run of unsafe frames before firing — so one stray detection doesn't page anyone. When it does fire, the Gmail API emails the offending frame to a configured recipient as evidence, then holds a cooldown before the next alert. Flask, OpenCV and PyTorch on CPU, with per-run detection reports exportable from the UI as a timestamped log.

Final-Year Project | ABESIT

Mr. Healthcare - Medical Chatbot

A knowledge-graph question-answering bot over a curated medical dataset. An Aho-Corasick automaton matches free text against roughly 2,800 disease, symptom and department terms, rule-based intent detection works out which of ten questions is being asked — causes, prevention, treatment, complications, which specialist to see — and the pair compiles into templated Cypher over a Neo4j graph, with returned rows formatted back into sentences. An offline ETL builds the graph from the source dataset, diseases as nodes and symptoms as edges. Deterministic and inspectable throughout, with no LLM in the loop. Vue front end on a Flask API.
