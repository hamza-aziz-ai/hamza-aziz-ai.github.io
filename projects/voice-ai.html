Production voice AI for drive-thru ordering

VoicePlug Inc. · AI Product Engineer

The problem

A spoken order must become a valid cart and reach a point-of-sale system. A fluent model response is insufficient: required choices, item limits and final submission need deterministic validation.

The system

FastAPI and Socket.IO carry streaming speech into a Gemini-based ordering flow. A menu-aware prompt guides replies, and a second model translates confirmations into Redis cart operations. MongoDB stores records, Jinja2 supplies brand-specific prompts, and the system integrates with four POS systems.

Engineering focus

The portfolio work focuses on modernization of this production ordering system: required-choice and per-item enforcement, a final cart check before submission, and staff handoff after repeated failures. Replays of real calls are used to validate behavior.

What this demonstrates

Combining probabilistic language understanding with explicit application rules and recoverable failure paths. This is a system overview; the proprietary code and customer call data are not published here.
