Conversational AI for college ERP data

Global InfoVentures Pvt. Ltd. · Assistant Engineer — AI

The problem

Questions about institutional data must resolve to the right ERP module and field mappings. Different institutes use different schemas, so generic free-form SQL generation is a poor fit.

The system

A FastAPI gateway handles audio transcription. A two-stage Rasa router chooses the ERP module and requests clarification when confidence is low. Milvus retrieves institute-specific field mappings and similar examples. Gemini generates constrained SQL fragments within a fixed payload contract; the ERP executes the request, and a second model summarizes returned rows.

Engineering focus

Schema grounding and routing separate language interpretation from the ERP execution interface. This portfolio example highlights retrieval, intent handling and backend integration rather than claiming a general-purpose autonomous database agent.

What this demonstrates

Retrieval, intent routing and constrained generation can connect natural-language questions to existing business systems while keeping execution behind the ERP interface.
